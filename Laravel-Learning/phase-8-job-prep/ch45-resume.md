# Chapter 45 — Resume Rewrite for Laravel Roles

You have 8+ years of PHP/CodeIgniter experience. That is your superpower — but only if you frame it right. A resume that says "8 years of CodeIgniter" reads as legacy. A resume that says "8 years of PHP delivering production web applications, now specializing in Laravel" reads as senior.

## The framing rules

1. **Lead with PHP, not the framework.** "Senior PHP Developer" not "CodeIgniter Developer."
2. **Quantify outcomes.** "Reduced page load by 40% by introducing Redis caching" beats "worked on caching."
3. **Speak the modern stack vocabulary.** Mention: REST APIs, OAuth/JWT, Redis, Queues, Docker, CI/CD, Git, MySQL, unit testing.
4. **Show Laravel credibility through projects, not titles.** A GitHub link with 3 polished Laravel projects beats "Laravel Developer" in your title with no proof.

## What hiring managers actually look for

1. **Production experience** — you have 8 years. Lean into it.
2. **Modern Laravel knowledge** — Eloquent depth, Sanctum, queues, tests. Show via projects.
3. **API design competence** — REST, versioning, error handling.
4. **Database skill** — joins, indexes, N+1 awareness.
5. **Testing habit** — Pest/PHPUnit feature tests.
6. **Deployment exposure** — even one Forge deploy counts.

## Common Mistakes

- Putting "JavaScript expert" when you're not. They will ask. Be honest.
- Listing every package you've ever used. Curate.
- Cover letter clichés. Skip them. The portfolio link is the cover letter.
- No GitHub link. Non-negotiable.
