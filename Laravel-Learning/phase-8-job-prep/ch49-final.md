## Long-term growth

Once you have a Laravel job, the next 1–3 years should focus on:

1. **Depth in Eloquent and SQL.** Performance tuning, indexes, query plans.
2. **Distributed systems basics.** Redis, queues, microservices, message queues.
3. **Cloud.** AWS at minimum (S3, RDS, EC2, SQS). Bonus: ECS or Lambda.
4. **DevOps fluency.** Docker, CI/CD, basic Linux ops.
5. **Frontend competence.** Real Vue or React, even if you mostly do backend. Modern jobs expect it.
6. **One specialization.** Pick one of: real-time (WebSockets, Reverb), e-commerce (Cashier, Stripe), data engineering (Spatie packages, queues), or security (OAuth, OWASP).
